# Product

<!-- impeccable:product-schema 1 -->

## Platform

web (a GitHub profile README, github.com/kadenkobashigawa)

## Users

Anyone who opens Kaden's GitHub profile: recruiters, other developers, people who found kstack.
They glance for a few seconds, then look at the pinned repositories.

## Product Purpose

The front page of the profile. It shows kstack's Robovac at work, so a visitor sees what kstack is
about before reading a word, and it stays as minimal as possible otherwise.

## Brand Commitments

- Kaden's picks (2026-11-01): a moving generated graphic, a fun image, as minimal as possible. No
  banner scene, no stats cards, no hosted widgets.
- The moving graphic is Robovac, drawn with kstack's own robot and dock parts, not a borrowed
  mascot (Clawd is Anthropic's).
- Everything is generated in the profile repo by its own script or Action. Nothing loads from
  someone else's server.
- Nothing private or client-specific; the profile is public.
- No school or degree in the README (Kaden, 2026-11-01), and no claim that kstack is a
  full-time job.

## Decisions

- 2026-11-01: the graph version, redrawn as GitHub's contribution panel with the dock in the
  bottom-left corner. Private contributions stay hidden, so it shows the public calendar only.
